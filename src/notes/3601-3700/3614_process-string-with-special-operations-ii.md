# 3614. Process String with Special Operations II

## Thoughts

Came up with the idea myself and a lot of the implementation, but the rest proved to be a challenge. Ended up having to refer to a video. Disappointing, since this is a relatively easy Hard problem.

## Analysis

Walk backwards through the string, and perform the opposite operations at each stage corresponding to the character. When the pointer and length match, we have found our result.
